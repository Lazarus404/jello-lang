# Files, paths, commands and the environment

The `std.io` package reaches the operating system: `std.io.File` reads and writes files,
`std.io.Path` works with paths, `std.io.Command` runs other programs and `std.io.Env` reads
environment variables. `std.sys.Platform` says which system a program runs on. Paths, contents and output are Bytes. Each module needs an import:

```text
import std.io.File as File;
import { readText, writeText } from std.io.File;
```

A call that waits for the operating system, such as a read or waiting for a command, parks only
the [process](04-concurrent.md) that makes it; the others run meanwhile.

## std.io.File

| Function | Description |
| --- | --- |
| `exists(path: Bytes): Bool` | whether there is a file or directory at `path` |
| `readText(path: Bytes): Bytes` | the whole contents of a file |
| `writeText(path: Bytes, contents: Bytes): Bool` | replaces the file's contents, creating it if needed; whether it succeeded |
| `remove(path: Bytes): Bool` | removes a file; whether there is none at `path` now |
| `makeDirs(path: Bytes): Bool` | makes a directory and any missing parents; whether it exists now |
| `listDir(dir: Bytes): Array<Bytes>` | the entries of a directory, but `.` and `..`, sorted by their bytes; a directory's name ends with `/` |

`readText` of a path that names no file the program can read, and `listDir` of one that names no
directory it can list, throw a message naming the path, so a missing file can be caught. A file
over 256 MiB, or one that goes away while it is read, still traps. Writing to `/dev/stdout` or
`/dev/stderr` adds to standard output or standard error, on every system and wherever the stream
goes; that is how a program prints as it goes.

```jello
// expect: started
// expect: hello, file true ["notes.txt", "sub/"] true false
import std.io.File as File;
import { tempDir } from std.sys.Platform;

File.writeText("/dev/stdout", "started\n");
let dir = tempDir() + "/file-demo";
File.makeDirs(dir + "/sub");
File.writeText(dir + "/notes.txt", "hello, file");
let text = File.readText(dir + "/notes.txt");
let there = File.exists(dir + "/notes.txt");
let entries = File.listDir(dir);
let removed = File.remove(dir + "/notes.txt");
text + " " + Std.string(there) + " " + Std.string(entries) + " " + Std.string(removed) + " "
  + Std.string(File.exists(dir + "/notes.txt"))
```

## std.io.Path

| Function | Description |
| --- | --- |
| `dirname(path: Bytes): Bytes` | `path` less its last component; `.` for a path of one component, `/` for one at the root |
| `filesUnder(dir: Bytes, suffix: Bytes): Array<Bytes>` | the paths of the files under `dir`, at any depth, whose names end with `suffix`, sorted by their bytes |

`filesUnder` follows links to directories, so a link back to one of its own ancestors makes it run
for ever.

```jello
// expect: /a/b . / | /one.md /sub/two.md
import { dirname, filesUnder } from std.io.Path;
import { makeDirs, writeText } from std.io.File;
import { tempDir } from std.sys.Platform;

let root = tempDir() + "/path-demo";
makeDirs(root + "/sub");
writeText(root + "/one.md", "1");
writeText(root + "/sub/two.md", "2");
writeText(root + "/sub/skip.txt", "3");
let relative = fn(p: Bytes): Bytes { p.slice(root.len(), p.len() - root.len()) };
let found = filesUnder(root, ".md").map(relative);
dirname("/a/b/c.txt") + " " + dirname("c.txt") + " " + dirname("/c") + " | " + found.join(" ")
```

## std.io.Command

A command runs a program as a child process. Its standard input is `/dev/null`, and its standard
output and error are captured whole, so a child never blocks on a full pipe. `start` does not wait
for the child, so several can run at once. `Command` is an abstract type, a handle to a child.

| Function | Description |
| --- | --- |
| `run(argv: Array<Bytes>, env: Array<Bytes>): Tuple<I32, Bytes, Bytes>` | runs a command to completion; its status, standard output and standard error |
| `start(argv: Array<Bytes>, env: Array<Bytes>): Command` | starts a command; a handle for the functions below |
| `wait(command: Command): I32` | waits for the command, once; its status |
| `stdout(command: Command): Bytes` | what it wrote to standard output, after waiting for it |
| `stderr(command: Command): Bytes` | what it wrote to standard error, after waiting for it |
| `result(command: Command): Tuple<I32, Bytes, Bytes>` | waits; its status, standard output and standard error |
| `finished(command: Command): Bool` | whether the command has ended, without waiting; once it has, the functions above return at once |
| `kill(command: Command): Bool` | kills the command's child at once if it has not ended, its status then being 137; whether it had not |
| `waitAny(commands: Array<Command>): I32` | the index of a command that has ended, waiting until one has; -1 for none |
| `cpuCount(): I32` | the number of processors the program may use, at least 1 |

- `argv[0]` is found on `PATH` unless it holds a slash; an empty `argv` traps, and an argument
  holding a NUL byte throws.
- Each item of `env` applies over the inherited environment, in order: `"NAME=VALUE"` sets `NAME`
  and a bare `"NAME"` unsets it.
- The status is the exit status; 128 plus the signal for a child a signal ended; 127, with the
  reason on standard error, for a program that cannot run; and 255 for a child that cannot be
  waited for.
- `waitAny` finds whichever command ends first, so a slow child holds up no other.
- A command handle collected before it is waited for kills its child.

```jello
// expect: 3 out err | 0 hi | 127
import std.io.Command as Command;

let (status, out, err) = Command.run(["sh", "-c", "printf out; printf err >&2; exit 3"], []);
let greeter = Command.start(["sh", "-c", "printf $GREETING"], ["GREETING=hi"]);
let code = Command.wait(greeter);
let (missing, _, _) = Command.run(["no-such-program-anywhere"], []);
Std.string(status) + " " + out + " " + err + " | " + Std.string(code) + " "
  + Command.stdout(greeter) + " | " + Std.string(missing)
```

```jello
// expect: 1 0 2
import { start, wait, waitAny } from std.io.Command;

let commands = [start(["sleep", "1"], []), start(["sh", "-c", "exit 2"], [])];
let first = waitAny(commands);
Std.string(first) + " " + Std.string(wait(commands[0])) + " " + Std.string(wait(commands[1]))
```

```jello
// expect: false true 137 true
import { finished, kill, start, wait } from std.io.Command;

let sleeper = start(["sleep", "100"], []);
let running = finished(sleeper);
let killed = kill(sleeper);
let status = wait(sleeper);
`${running} ${killed} ${status} ${finished(sleeper)}`
```

## std.io.Env

| Function | Description |
| --- | --- |
| `getEnv(name: Bytes): Bytes` | the value of environment variable `name`; empty when it is unset |

```jello
// expect: true true
import { getEnv } from std.io.Env;

Std.string(getEnv("PATH") != "") + " " + Std.string(getEnv("NO_SUCH_VARIABLE_SET_HERE") == "")
```

## std.sys.Platform

Paths in `std` use `/` on every system, Windows included, so most programs never need to know
where they run. For the few that do:

| Function | Description |
| --- | --- |
| `os(): Bytes` | the operating system: `macos`, `linux` or `windows` |
| `arch(): Bytes` | the processor: `arm64` or `x64` |
| `version(): Bytes` | the Jello release the running VM's standard library belongs to, such as `0.1.1` |
| `tempDir(): Bytes` | the directory for temporary files, with `/` between its components and none at the end unless it is the root: `$TMPDIR` when it is set, then on Windows `%TEMP%` or `%TMP%`, else `/tmp` |

```jello
// expect: true true true
import { arch, os, tempDir } from std.sys.Platform;

let known = ["macos", "linux", "windows"].contains(os());
Std.string(known) + " " + Std.string(["arm64", "x64"].contains(arch())) + " "
  + Std.string(!tempDir().endsWith("/"))
```
